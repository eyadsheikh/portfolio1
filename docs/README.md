# Portfolio Website — بورتفوليو احترافي

## لماذا هذا الموقع يستحق > $500؟
- تصميم عصري متجاوب بالكامل، مبني من الصفر مع نظام ألوان وهوية قابلة للتخصيص بسهولة.
- تجربة مستخدم ممتازة، سرعة تحميل عالية، وتحسينات SEO متقدمة (meta tags, بنية HTML دلالية).
- كود CSS منظم مع متغيرات وتعليقات، قابل لإعادة الاستخدام والتطوير، وموثق بالكامل.
- جاهز للنشر الفوري على Netlify أو GitHub Pages، مع ملفات منظمة وصور محسنة.

---

## التركيب والتعديل

1. **التركيب:**  
   - فك ضغط الملفات أو انسخها إلى مجلد جديد.
   - افتح `index.html` في المتصفح مباشرة.

2. **تغيير الألوان/الخطوط:**  
   - افتح `css/styles.css` وعدل المتغيرات في القسم `:root`.
   - لتغيير الخطوط، حدث رابط Google Fonts في `<head>`.

3. **تغيير الصور والشعار:**  
   - استبدل الصور في مجلد `assets/` (مثلاً: `hero.webp`, صور المشاريع، الأيقونات).

4. **تعديل الروابط:**  
   - حدث روابط التواصل الاجتماعي وروابط المشاريع في HTML.

---

## قائمة الملفات

- `index.html` — الصفحة الرئيسية
- `about.html` — صفحة عنّي
- `projects.html` — صفحة المشاريع
- `contact.html` — صفحة اتصل بي
- `css/styles.css` — جميع الأنماط
- `assets/` — صور، أيقونات، favicon
- `README.md` — هذا الملف

---

## تعليمات النشر

- يمكنك رفع المجلد كاملاً إلى [Netlify](https://netlify.com) أو [GitHub Pages](https://pages.github.com).
- تأكد من أن جميع الصور مضغوطة (استخدم [tinypng.com](https://tinypng.com)).
- لتوليد لقطات شاشة:  
  - افتح الموقع على متصفحك بحجم شاشة mobile (320px)، tablet (768px)، desktop (1440px).
  - التقط صورة للشاشة واحفظها في `assets/screenshots/`.

---

## ملاحظات تقنية

- التصميم mobile-first مع نقاط كسر 480px, 768px, 1024px, 1440px.
- جميع العناصر قابلة للتنقل عبر الكيبورد (tab order).
- صور المشاريع تدعم `srcset` (يمكنك إضافة ذلك لاحقاً).
- جميع الروابط والأزرار تدعم حالات focus للوصولية.
